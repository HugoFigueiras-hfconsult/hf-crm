# Handover: HF-CRM auf Azure SQL + SQL MCP Server (für Claude Code)

Stand: 2026-11-11, 22:30 · Owner: Hugo (HF-Consult, Einzelunternehmen, M365-Tenant `hf-consult.de`)
Ziel dieses Dokuments: Nahtlose Fortsetzung in Claude Code. **Jeder Schritt wird im Repo dokumentiert** (Skripte + Log), nichts nur im Portal klicken.

---

## 1. Ziel

Eigenes CRM für Hugos Finanzberatung. Eine Datenbank, auf die zugreifen:

| Konsument | Zugriff | Zweck |
|---|---|---|
| Claude-Routine (Cloud, Max-Abo) | Eigener Connector → SQL MCP Server | Termin-Vor-/Nachbereitung, Ablauferinnerungen, Quartalstermine |
| Claude-Artefakt (Dashboard) | `mcp`-Capability über denselben Connector | Mandanten durchtabben, live laden (speichert selbst nichts) |
| Copilot-Agent (Copilot Studio, M365 Copilot Business) | Azure SQL als Wissensquelle | Interaktive Abfragen in Teams/Chat |
| Später: Telegram-Bot | Cloudflare Worker → Routine-`/fire` | Proaktive Kommunikation Hugo + Ehefrau |

## 2. Entscheidungen (mit Begründung)

| Thema | Entscheidung | Begründung / verworfene Alternativen |
|---|---|---|
| DB | **Azure SQL Database, Free Offer** | Daten im eigenen Tenant, MS-AVV, EU. Supabase verworfen (Hugo will MS-Seite; 500 MB-Limit-Sorge). Supabase bleibt **Fallback** (offizieller Claude-Connector, 5 Min Setup) |
| API/MCP | **Data API builder (DAB) ≥ 2.0 mit SQL MCP Server** | Liefert REST + MCP aus einer `dab-config.json`. GA seit 06/2026. Kein offizieller Azure-SQL-Connector in Claude vorhanden |
| Hosting DAB | Azure Container Apps (Consumption, min. Replicas 0) | Free Grant. ACR vermeiden (Basic ≈ 5 $/Monat) → Image in **GitHub Container Registry** |
| Auth DAB | Entra ID (JWT, Provider `EntraId`) | Claude Custom Connector mit eigenem OAuth-Client |
| Frontend | Claude-Artefakt statt Power Apps / Static Web App | Power Apps + SQL-Connector = Premium (~20 $/Nutzer). SWA nur falls später nötig |
| Power Apps / Lists / Dataverse for Teams | Verworfen | Lists keine echte DB; Dataverse for Teams: keine neuen Umgebungen ab 15.11.2026 |
| Blaze SQL / Composio | Verworfen | 150–800 $/Monat bzw. zusätzlicher Dienstleister für Mandantendaten |
| Claude-Plan | Max (privat, Consumer Terms) bleibt vorerst | Team-Plan (AVV) bewusst später (spätestens volle Selbstständigkeit Ende 2027). Hugo trägt Risiko bewusst |
| Copilot | M365 Copilot Business vorhanden | Claude-Modelle in Copilot (Anthropic-Subprozessor) aktiviert, Rollout für Tenant ab 07.01.2027. Credits/Cowork **nicht** nutzen (teuer) |

## 3. Harte Regeln (für den Agenten und dieses Projekt)

|---|---|

### Phase 3 – Schema

`db/migrations/001_init.sql` (T-SQL, bewusst portabel). Entwurf, mit Hugo abstimmen:

| Tabelle | Spalten (Kern) | Hinweis |
|---|---|---|
| `Mandanten` | `Id uniqueidentifier PK`, `Kuerzel nvarchar(20) UNIQUE`, `Vorname`, `Nachname`, `Email`, `Telefon`, `Status`, `ErstelltAm datetimeoffset`, `GeaendertAm` | Anrede immer „Du“ |
| `Vertraege` | `Id`, `MandantId FK`, `Sparte`, `Gesellschaft`, `VertragsNr`, `Beginn date`, `Ablauf date`, `KuendigungsfristTage int`, `BeitragMonat decimal(10,2)`, `Status`, `DokumentLink nvarchar(500)` | Basis für Ablauferinnerungen |
| `Termine` | `Id`, `MandantId FK`, `Start datetimeoffset`, `Ende`, `Typ` (Erst/Quartal/Service), `OutlookEventId nvarchar(200)`, `Notiz nvarchar(2000)` | Outlook bleibt führend für Kalender |
| `TerminZusammenfassungen` | `Id`, `TerminId FK`, `Zusammenfassung nvarchar(max)`, `TranskriptLink nvarchar(500)` | Volltranskript in OneDrive |
| `Aufgaben` | `Id`, `MandantId FK NULL`, `Titel`, `Faellig date`, `Status`, `Quelle` (Agent/Hugo) | |
| `AgentVerlauf` | `Id`, `Kanal` (telegram), `Absender`, `Nachricht nvarchar(4000)`, `Zeit` | Gedächtnis zwischen Routine-Läufen |

Ausführen als Entra-Admin aus Cloud Shell/lokal: `sqlcmd -S $SQL_SERVER.database.windows.net -d $SQL_DB --authentication-method ActiveDirectoryDefault -i db/migrations/001_init.sql`.

### Phase 4 – DAB / SQL MCP Server

| # | Schritt | Detail |
|---|---|---|
| 4.1 | Lokal `dab` CLI (≥ 2.0) | `dotnet tool install -g Microsoft.DataApiBuilder` |
| 4.2 | Config | `dab init --database-type mssql --connection-string "@env('DAB_CONNSTRING')" --host-mode production` |

| 4.4 | MCP aktivieren | MCP-Endpunkt `/mcp` in `runtime` aktivieren (Flag-Namen per `dab configure --help` prüfen) |
| 4.5 | Auth | `dab configure --runtime.host.authentication.provider EntraId --runtime.host.authentication.jwt.audience <APP_ID_URI> --runtime.host.authentication.jwt.issuer https://login.microsoftonline.com/<TENANT_ID>/v2.0` |
| 4.6 | Image | `dab/Dockerfile`: `FROM mcr.microsoft.com/azure-databases/data-api-builder:<2.x>` + `COPY dab-config.json /App/dab-config.json`. Build/Push via GitHub Action nach `ghcr.io/<user>/hf-crm-dab` |
| 4.7 | Container App | `az containerapp env create -g $RG -n $CAE -l $LOC` · `az containerapp create -g $RG -n $CA --environment $CAE --image ghcr.io/... --ingress external --target-port 5000 --min-replicas 0 --max-replicas 1 --system-assigned` |
| 4.8 | DB-Zugriff per Managed Identity | In SQL als Entra-Admin: `CREATE USER [ca-hf-crm-dab] FROM EXTERNAL PROVIDER; ALTER ROLE db_datareader ADD MEMBER [ca-hf-crm-dab]; ALTER ROLE db_datawriter ADD MEMBER [ca-hf-crm-dab];` |
| 4.9 | Connection String (Secret) | `Server=tcp:<server>.database.windows.net;Database=hfcrm;Authentication=Active Directory Managed Identity;Encrypt=True;` als Container-App-Secret → Env `DAB_CONNSTRING` |
| 4.10 | Custom Domain | `mcp.hf-consult.de` an Container App (CNAME + TXT bei DNS-Anbieter, kostenloses Managed Cert). **Nötig für 5.2** |
| 4.11 | Test | REST `GET https://mcp.hf-consult.de/api/Mandant` mit Token → 200 · MCP mit MCP Inspector |
